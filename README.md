## Μεταγλώττιση και εκτέλεση (Java 11)
```
cd ex1
javac -encoding UTF-8 --release 11 *.java
java PT1        # ή PT2, PT3

cd ../ex2
javac -encoding UTF-8 --release 11 *.java
java KMeans
```
Τα προγράμματα διαβάζουν τα δεδομένα από `../data/`.
Πριν την υποβολή, τα αρχεία δεδομένων αντιγράφονται μέσα στον κατάλογο κάθε άσκησης και αλλάζει το path στον κώδικα.

## Κανόνες ομάδας
- Μόνο Java 11, χωρίς εξωτερικές βιβλιοθήκες (όχι records, text blocks, switch expressions).
- Ένα branch ανά μέλος (π.χ. `part-a`, `part-b`, `part-c`), pull request, review από άλλο μέλος.
- Κάθε μέλος αλλάζει μόνο τα αρχεία του. Αλλαγές στο κοινό συμβόλαιο (`docs/ex1-roles.md`, ενότητα 3) γίνονται με συνεννόηση.
- Μηνύματα commit στα αγγλικά.
- Η εξέταση είναι διά ζώσης: **όλοι καταλαβαίνουν όλο τον κώδικα**.
